# سمساری حرفه‌ای چندنفره

## راه‌اندازی در Render
1. این فایل‌ها را در ریشه همان مخزن GitHub قرار بده: `index.html`، `server.js` و `package.json`.
2. اگر فایل مدل `d.glb` را داری، آن را هم در ریشه مخزن کنار `index.html` قرار بده.
3. در Render نوع سرویس باید **Web Service** باشد، نه Static Site.
4. تنظیمات:
   - Build Command: `npm install`
   - Start Command: `npm start`
5. بعد از Deploy، آدرس عمومی Render را باز کن.

## نکته
- این نسخه همگام‌سازی پایه موقعیت بازیکنان و نمایش بازیکنان دیگر را اضافه می‌کند.
- پول، موجودی، سفارش‌ها و مشتری‌ها هنوز محلی هستند و بین بازیکنان مشترک نیستند.
- فایل `d.glb` در آپلود اولیه وجود نداشت؛ بازی بدون آن هم اجرا می‌شود، ولی مدل سفارشی بازیکن بارگذاری نمی‌شود.
